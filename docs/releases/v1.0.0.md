# PlaceDrift 1.0.0

首个正式版，基于经过数天实机使用的 Build 17。与 Public Beta 2 相比，应用功能保持一致；App 和分享扩展的版本号同步更新为 1.0.0。

## 功能

- 在 iOS 27+ 上通过 CoreDevice RemotePairing、DVT `LocationSimulation` 设置、更新和恢复模拟位置。
- 从 Apple 地图、高德地图和百度地图直接分享地点；在设备本机解析坐标。
- 自动探测 RemotePairing 服务并以有效的 Pair Verify 响应验证传输。
- 支持 SideStore 重签后的地图分享接收器端口探测。

## 使用要求

- 开启 iPhone 开发者模式，并完成 PlaceDrift 配对。
- 连接支持 `10.7.0.1` self-loop 的 TUN App。已实测配置包括 LocalDevVPN、Clash Mi、Clash 和 Karing。
- PlaceDrift 本身不会启动 VPN。下载的 IPA 未签名，安装前需要自行合法签名，并保留 `PlaceDriftShare.appex`。

后台会话仍受 iOS 调度策略影响；长期锁屏表现可能因设备和系统版本而异。配置和操作步骤见 [README](https://github.com/xepes0/PlaceDrift#readme)。
