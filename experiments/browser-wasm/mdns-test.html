RemotePairing mDNS Test

This page contains no pairing record. It asks Clash Mi's local VLESS/WebSocket bridge to send a UDP mDNS query for _remotepairing._tcp.local.

Start with 10.7.0.1. If it returns no datagram, try multicast. A useful response should contain PTR/SRV/TXT records and normally an identifier/authTag in TXT.
